## Overview
HopText is a messaging application currently in development designed around offline, local-area end-to-end encrypted messaging using Bluetooth. It allows users to set designated "carriers" who can carry an encrypted message from the sender to the receiver without that carrier having access to the data themselves.

## Purpose
Many mobile users utilize inherently insecure messaging methods. These include applications that utilize the SMS protocol, which is rarely encrypted, and third-party messaging applications such as [Telegram](https://telegram.org/), which is not end-to-end encrypted by default, or [Messenger](https://www.messenger.com/?_rdr), which consists of entirely proprietary code and therefore cannot be vetted accurately. Additionally, while [Signal](https://signal.org/) is often considered the current ideal for secure and private communication, the service relies entirely on the Signal servers being reachable, which may not always be possible.

HopText is an offline, decentralized, end-to-end encrypted messaging platform that exists to address the concerns mentioned above. Utilizing Bluetooth data transfers, HopText allows for secure messaging between users in a local area. If a desired recipient is not within range of the message being sent, a user-verified "carrier" can receive the message and deliver it to the intended recipient once the carrier is within range of the original recipient. This can create a network of offline message relaying in a local community without needing to worry about the integrity of a centralized messaging service.

The application is FOSS and entirely community-maintainable, giving it an additional degree of resilience.
